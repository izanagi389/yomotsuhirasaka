# 絶対に破ってはいけない約束

各約束には、`tests/invariants/` に対応する自動テストがあります。テストの名前は「テスト名」列で始まり、説明には「約束」列の文がそのまま書かれます。

- **M**: その約束のテストを必ず通すマイルストーン。`current-milestone` 以前のものはCIで必ず実行され、すべて通る必要があります。
- **根拠**: 判断記録（`docs/history/`）の質問番号。

この一覧とテストの変更には、リポジトリの持ち主の承認が必要です。
