# 編集者・ワークスペースの管理者向け手順書

記事を書く人と、ワークスペースを預かる人のための手順書です。v1.0 では主な作業に絞っています。

- [編集者の章](editor.md): ログイン、やること、記事を書く、プレビュー、公開する、訂正する、見直す、AI 支援、メディア、アカウント
- [ワークスペースの管理者の章](workspace-admin.md): 所属者、キー、Webhook、フックの秘密、予算、チャットボット、質問ログ、監査ログ

ロールごとにできることは [ロールと権限の一覧](../reference/roles-and-permissions.md)、言葉の意味は [用語集](../reference/glossary.md) にあります。
