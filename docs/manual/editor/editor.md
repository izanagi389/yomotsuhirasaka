# 編集者の章

## はじめてログインする

招待のリンクを開いて「承諾する」を押します。新しい人はパスワードを決めます（12文字以上。同じ文字の繰り返し、連続した文字や数字、キーボードの並び、メールアドレスやサイト名を含むものは使えません）。

次に、多要素認証を設定します。既定では全員に必要で、設定が済むまでほかの操作はできません。

1. 「アカウント」→「セキュリティ」の「認証アプリ」で「設定を始める」を押します。
2. 表示された QRコードを認証アプリ（Google Authenticator など）で読み取り、6桁のコードで確かめます。読み取れないときは、QRコードの下の鍵を入力します。
3. 表示された**復旧コードを安全な場所に保管します**。この画面でだけ表示されます。

端末の生体認証やセキュリティキーを使う「パスキー」も登録できます。

「プロフィール」で表示名を決めてください。レビューを頼む相手を選ぶ画面などで、ほかの所属者に見える名前です。

パスワードを忘れたら、ログインの画面の「パスワードを忘れた場合」から再設定します。メールが届かないサーバーでは、サーバー管理者に頼んでください。シングルサインオンだけでログインしている人は、IdP（会社のアカウントなど）で回復します。心当たりのないログインがないかは「セッションと履歴」で確かめられます。

## 何から始めるか

ワークスペースを開くと「やること」が出ます。あなたが対応できることが、急ぐものから順に並んでいます。開くと、記事の編集画面で、対応する欄が開きます。何もなければ「いま対応することはありません。」と出ます。

| 種類 | すること |
|---|---|
| レビュー待ち | 依頼された記事を見て、公開するか差し戻します |
| 差し戻し | コメントを見て直し、もう一度依頼します |
| 説明を書いていない訂正 | 右の欄の「履歴」で訂正の説明を書きます |
| 確認期限切れ | 内容を確かめて「確認済みとして記録」を押します（下の「内容を見直す」） |
| 原文が更新された・原文が訂正された | 翻訳の記事を、原文に合わせて直します |
| 予約の失敗・公開を待っている予約・訂正で取り消された予約 | 予約を確かめ、必要なら予約し直します |
| 予算切れ・埋め込みのモデルがない | ワークスペースの管理者かサーバー管理者に知らせます。公開はこれまでどおりできます |
| 通知 | 内容を読んで、必要なことをします |

以前の「要対応」の画面の URL を開いたときも、「やること」に移ります。

## 記事を書く

1. 「記事」→「新しい記事」で、コンテンツタイプとロケールを選んで「作成する」を押します。
2. 中央の上の大きな欄にタイトルを、その下に本文を書きます。入力は自動で保存され、画面に「保存済み」と出ます。
3. スラッグ、要約、アイキャッチなど、ほかの項目は右の欄の「項目」タブで入れます。スラッグ（英小文字、数字、ハイフン）を入れると、公開 URL が決まります。

### 本文のエディタ（ブロックとクラシック）

本文の書き方は2通りあり、上の帯の「ブロック／クラシック」か、左下のアカウントのメニューの「本文のエディタ」で切り替えます。どちらで書いても、保存される本文は同じです。途中で切り替えても内容は変わりません。選んだものはブラウザごとに覚えます（最初は「ブロック」）。

**ブロック**では、段落、見出し、画像などを1つずつの「ブロック」として扱います。

- **ブロックを入れる**: 空の行の「＋「/」でブロックを選ぶ」を押すか、行の頭で「/」を打つと、ブロックの一覧が出ます。続けて文字を打つと絞り込めます（「見出し」「h2」「quote」など）。↑↓ で選んで Enter で入れます。Esc で閉じます。
- **並べ替える**: ブロックの左のつまみ（⋮⋮）をドラッグします。つまみを押すと「上へ」「下へ」「複製」「削除」も選べます。キーボードでは Alt+Shift+↑↓ で、カーソルのあるブロックを動かせます。スマートフォンではドラッグせず、つまみのメニューで動かします。
- **文字を飾る**: 文字を選ぶと、すぐ上に太字、斜体、取り消し線、コード、リンクのボタンが出ます。
- **ブロックの設定**: 右の欄の「ブロック」タブに、選んだブロックの設定が出ます。見出しの階層、画像の代替テキストと装飾画像の印、埋め込みの URL、テンプレートの部品（カスタム部品）の項目です。画像や部品を選ぶと、このタブが開きます。
- 元に戻すときは ⌘Z（Windows は Ctrl+Z）、やり直すときは ⌘⇧Z（Ctrl+Shift+Z）を使います。

**クラシック**では、本文の上のツールバーで、見出し、箇条書き、引用、コードブロック、リンク、画像、埋め込みなどを使います。画像の代替テキストや部品の項目は、本文の中で入れます。

どちらでも、次の点は同じです。

- **画像には「代替テキスト」を入れるか、「装飾画像」の印を付けてください。** どちらもない画像があると公開できません。ブロックでは、そのような画像に「代替テキストなし」の印が出ます。
  AI 支援が有効で、画像を読むモデルが設定されていれば、代替テキストの欄の下の「AIで案を出す」で案を出せます（[AI 支援](#ai-支援)）。
- 埋め込みは、許可された提供元の https の URL だけです。
- 使える画像は JPEG、PNG、WebP、GIF です。アップロードのときに写真の位置情報などは取り除かれます。
- サムネイルのような「画像のフィールド」は、「画像を選ぶ」でメディアから選ぶか、「アップロード」で新しく入れます。本文の画像と同じく、代替テキストか装飾画像の印が必要です。
- **メディアは URL を知っていれば誰でも見られます。** 下書きの記事で使っている画像も同じです（URL は推測できない名前になっています）。公開前の秘密の画像は置かないでください。

### 同時に編集したとき

ほかの人が編集中の記事は「{名前} さんが編集中です」と出て、閲覧だけになります。「編集を引き継ぐ」で引き継げます（権限の設定によります）。

「他の人がこの下書きを先に保存しました」と出たら、自動保存は止まっています。**読み直すと、まだ保存していない変更は消えます。** 必要な部分をコピーしてから読み直してください。

## プレビューする

記事の編集画面の上の帯の「プレビュー」で、公開前の下書きを、実際のサイトでの表示で確かめられます（ライブプレビュー）。

1. 「プレビュー」を押すと、本文の代わりにサイトが表示されます（「編集に戻る」で本文に戻ります）。つながるまでは「サイトにつないでいます…」と出ます。
2. つながると「保存のたびに更新します」と出ます。本文で書いて保存（自動保存を含む）するたびに、表示が新しくなります。
3. 表示がおかしいときは「開き直す」を押します。大きな画面で見たいときは「別タブで開く」を使います。

- プレビューに出るのは、この記事の下書きだけです。ほかの記事は公開中の内容で表示されます。
- プレビューのリンクは短い時間で使えなくなります（最長10分）。時間がたったら、もう一度開いてください。
- **表示が更新されない、または公開中の内容が出るときは、ブラウザが画面の中の枠のクッキーを止めています。** 「別タブで開く」を使ってください。
- 「公開URLを作れないため、プレビューを開けません」と出たら、スラッグを入れてください。
- 「この記事の公開URLのサイトは、プレビューを許すサイトに設定されていません」と出たら、ワークスペースの管理者に設定を頼みます（管理者には「設定を開く」が出ます）。

## レビューを頼む（執筆者）

執筆者は公開できません。右の欄の「レビュー」の「レビューを依頼する」で、公開できる人に頼みます。差し戻されたら、コメントを見て直し、また依頼します。

編集者と管理者は、依頼を見て公開するか「差し戻す」を押します。依頼がなくても公開できます。

## 公開する

1. 「公開」を押すと「公開の確認」が開きます。
2. 公開できない理由、公開 URL、変更されたセクションを確かめます。URL が変わるときは知らせが出ます（古い URL は履歴に残り、リダイレクトされます）。
3. 「ほかの記事との食い違い（AI）」が出ていれば、目を通します。AI 支援を有効にしたワークスペースだけに出ます。公開はこの結果を待たずにできます。
4. 「公開する」を押します。

公開中の記事を直して公開すると、新しい版になります。右の欄の「履歴」で過去の版とURLの履歴を見られます。

### 予約公開

「そのほかの操作」→「予約公開…」で時刻を決めます。**その時点の下書きが予約版として固定されます。** 後で下書きを編集しても予約版は変わりません。その編集も公開するには「予約し直す」を押してください。

### 非公開と削除

どちらも、記事の編集画面の一番下の「危険な操作」を開いて行い、確認が出ます。「非公開にする」は公開サイトから取り下げます。下書きと版の履歴は残ります。「削除する」は公開も止め、画面からは元に戻せません（管理者と編集者だけ）。どちらも、配信、検索、回答からすぐに外れます。

## 誤りを訂正する

公開中の記事の誤りを直すときは、ふつうの公開ではなく**「そのほかの操作」→「訂正として公開」**を使います。

- 訂正があったことと、影響したセクションが、読者に公開されます。**変更前の本文や差分は公開されません。**
- 「訂正の説明」に、何をどう直したかを書きます（任意）。定型文からも選べます。後から右の欄の「履歴」で書き直せます。
- 旧版は、すぐに検索とチャットボットの根拠から外れます。
- 訂正は予約できません。予約がある記事を訂正として公開すると、予約は取り消されます。

数値、日付、リンクが変わっていると、公開の確認で「誤りの訂正ですか？」と知らせます。

### 版の本文を消す（管理者）

個人情報の削除依頼などで、古い版の本文を消すときは右の欄の「履歴」の「本文を抹消」を使います（管理者だけ）。版の番号や日時の記録は残り、本文だけがすべての API から消えます。

- 元に戻せません。
- 公開中の版は抹消できません。問題の箇所を直した版を訂正として公開するか、非公開にしてから抹消します。
- **抹消より前に取ったバックアップには残ります。**
- 翻訳された記事に同じ内容が残っていないかも確かめてください。

## 内容を見直す（鮮度）

右の欄の「鮮度」に「最終確認日」と「確認期限」があります。内容が今も正しいことを確かめたら「確認済みとして記録」を押します。版は作られません。メモは管理画面だけに残ります。

期限が切れた記事は「やること」に出ます。チャットボットの回答でも、断定を避けるようになります。

AI 支援が有効なら、右の欄の「AI」タブの「古くなっていそうな箇所を探す」で、バージョン番号、価格、日付、外部リンクを挙げてもらえます（[AI 支援](#ai-支援)）。

## 翻訳する

右の欄の「翻訳」の「翻訳を作る」で、下書きを複製して別のロケールの記事を作ります。原文が更新や訂正されると「やること」に出ます。

## 公開設定

右の欄の「公開設定」のスイッチです（変えるには「方針に関わるスイッチ」の権限が要ります）。

| スイッチ | 内容 |
|---|---|
| チャットボットに使う | この記事を回答の根拠に使います |
| 外部AI向けの素材に含める | Markdown 版や `llms.txt` に含めます |
| 学習への利用を拒否する | AI の学習に使わないよう意思表示します。クローラーへの意思表示で、技術的に止めるものではありません |

## 関連記事

右の欄の「関連記事」で、自動で選ばれた関連記事を確かめ、固定や除外ができます（編集者と管理者）。

## AI 支援

ワークスペースの管理者が AI 支援を有効にしていると、右の欄の「AI」タブで、書いている記事について AI の手助けを受けられます。**どれも、ボタンを押したときだけ動きます。** 送るのは保存済みの下書きなので、直したばかりの内容は、保存されてから押してください。

| 項目 | すること |
|---|---|
| 見出しの形 | 見出しの段の飛び（H2 の次に H4 など）、空の見出し、同じ名前の見出しを出します。AI は使わず、書くたびにその場で確かめます |
| 構成の確認（AI） | 「構成を確認」で、論理の流れ、答えられなかった質問、近い記事との重なりを AI が指摘します |
| 校正（AI） | 「校正する」で、見出しごとに AI が読み、「誤り」（誤字脱字、表記ゆれ、文法）と「読みやすさ」の提案を出します |
| 要約の案（AI）・タイトルの案（AI） | 「要約の案を出す」「タイトルの案を出す」で、案を出します（要約は3つまで、タイトルは5つまで） |
| 代替テキストの案（AI） | 代替テキストのない画像の一覧です。画像ごとの「AIで案を出す」で、案を3つまで出します |
| 見直しの手がかり（AI） | 「古くなっていそうな箇所を探す」で、バージョン番号、価格、日付、外部リンクを挙げます |

- **AI の提案は、「当てる」を押すまで記事を変えません。** 当てたあとは、自分で書いたのと同じ扱いです。元に戻すときは、本文なら ⌘Z（Ctrl+Z）で、項目なら欄で書き直します。
- 校正の「当てる」は、元の語句が同じ段落に1か所だけあり、太字やリンクなどの書式を含まないときだけ出ます。それ以外は、提案を見ながら本文で直してください。校正の結果が「途中までの提案です」となったときは、予算などのために残りの見出しを見ていません。
- 要約の案とタイトルの案は、テンプレートで要約やタイトルの項目が決められているときだけ出ます。
- 代替テキストの案は、サーバーかワークスペースに「画像を読むモデル」が設定されているときだけ使えます。送るのは、その画像（5MB 以下の JPEG、PNG、WebP、GIF の1枚目）と前後の段落です。ブロックでは画像の「ブロック」タブ、クラシックでは本文の画像の欄からも出せます。
- 構成の確認に答えられなかった質問を含めるのは、「質問ログの閲覧」の権限があり、質問ログが有効で、再認証したばかりのときだけです。含めたときは、質問ログの閲覧として監査ログに残ります。権限がなければ、その旨を出して質問を除いて確かめます。
- ボタンの下に、使うトークン数の最大の見込みが出ます。「編集者向けの支援」の予算から使います。予算が尽きると「今月の上限に達しました」（または「今日の上限に達しました」）と出ますが、公開はこれまでどおりできます。

AI の説明や案は、記事のロケールの言語で書くよう指示しています。日本語の記事で、AI が別の言語（中国語や英語など）で書いたときは1回だけ取り直し、それでも違えば、その説明や案は出しません（食い違った記事や、古くなっていそうな語句は出ます）。この取り直しも AI 支援の予算から使います。

AI の結果には見落としや誤りがありえます。事実は自分で確かめてください。**AI 支援を有効にしたワークスペースでは、ボタンを押すと、公開前の下書き（代替テキストの案では画像も）が LLM の提供会社に送られます。**

## メディア

「メディア」で、ワークスペースの画像を一覧できます。

- **アップロード**: 「アップロード」を押して画像を選びます（閲覧者以外）。記事の本文からも追加できます（ブロックでは「/」の一覧の「画像」、クラシックではツールバー）。使える形式と注意は「記事を書く」のとおりです。
- **使用量**: 「使用量: 〇 / 〇」で、ワークスペースの容量の上限に対する使用量が分かります。上限はサーバー管理者が決めます。
- **使っている記事**: 画像を開くと、どの記事の下書きや版で使っているかが出ます。
- **削除**（管理者と編集者）: 「削除」を押すと、確認が出ます。**元に戻せません。** 記事で使っている画像は「このメディアは記事で使われています」と出て、それでも削除すると、その記事の画像は表示されなくなります。

## アカウント

画面の左下（ワークスペースの外では右上）に出ている自分の名前を押すと、メニューが開きます。「セキュリティ」「プロフィール」「セッションと履歴」「個人トークン」を選べます。言語と表示（明るい・暗い・OS の設定に従う）の切り替え、ログアウトも、このメニューにあります。表示の選択は、使っているブラウザにだけ覚えます。

### セキュリティ

- **認証アプリ**: 多要素認証の設定（「はじめてログインする」のとおり）。
- **パスキー**: 「名前（例: 仕事のノートPC）」を入れて「パスキーを登録」を押し、端末の生体認証やセキュリティキーで登録します。登録や解除の後は、ほかの端末のログインが終了します。
- **復旧コード**: 「復旧コードを作り直す」で新しくします。**これまでの復旧コードは使えなくなります。** 新しいコードはこの画面でだけ表示されます。
- **パスワードの変更**: 今のパスワードと新しいパスワードを入れます。変えると、ほかの端末のログインは終了します。
- **外部のアカウント**: シングルサインオンが使えるサーバーでは、会社のアカウントなどをひも付けて、そのアカウントでログインできます。ログインの手段がほかにないときは、解除できません。

重い操作の前には、本人の確認（コードの入力など）が求められます。

### セッションと履歴

- **ログイン中のセッション**: いまログインしている端末の一覧です。心当たりのないものは「終了させる」を押し、パスワードの変更も考えてください。
- **ログインの履歴**: 日時、ブラウザ、IP アドレス、国と、新しい端末からのログインかどうかが出ます。

### 個人トークン

CLI（記事の取り込みやテンプレートのデプロイ）で使うトークンです。ふだん記事を書くだけなら要りません。

1. 「名前」「権限」（読む・書く・デプロイ）「有効な日数（最長365日）」「使えるワークスペース」を決めて「発行する」を押します。
2. **トークンは発行のときに一度だけ表示されます。** 安全な場所に保管してください。

- 使えるのは、トークンの権限と、その時点のあなたのロールの両方で許される操作だけです。
- デプロイの権限は、ほかの権限と一緒に選べず、有効期間は最長30日です（サーバー管理者だけが発行できます）。
- 要らなくなったトークンや、漏れたかもしれないトークンは「失効させる」を押します。そのトークンを使っている CLI は使えなくなります。

### プロフィール

「表示名」を決めます。レビューを頼む相手を選ぶ画面や、レビューの履歴で、ほかの所属者に見える名前です（1〜50文字。いつでも変えられます）。

## 困ったとき

| 表示 | すること |
|---|---|
| スキーマの移行待ちのため、編集と公開を止めています | サーバー管理者に知らせて、終わるのを待ちます。公開中の記事は配信され続けます |
| テンプレートの〜に問題があり | テンプレートの開発者に知らせます。編集者が直すものではありません |
| テンプレートの公開前のフックが、公開を止めました | 表示された理由に従って直します |
| 見つかりません | ワークスペースに所属していないか、記事が削除されています |

エラーの一覧は [エラーコード](../reference/error-codes.md) にあります。
