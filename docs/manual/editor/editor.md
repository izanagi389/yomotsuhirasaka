# 編集者の章

## はじめてログインする

招待のリンクを開いて「承諾する」を押します。新しい人はパスワードを決めます（12文字以上。同じ文字の繰り返し、連続した文字や数字、キーボードの並び、メールアドレスやサイト名を含むものは使えません）。

次に、多要素認証を設定します。既定では全員に必要で、設定が済むまでほかの操作はできません。

1. 「アカウント」→「セキュリティ」の「認証アプリ」で「設定を始める」を押します。
2. 表示された鍵を認証アプリ（Google Authenticator など）に入れ、6桁のコードで確かめます。
3. 表示された**復旧コードを安全な場所に保管します**。この画面でだけ表示されます。

端末の生体認証やセキュリティキーを使う「パスキー」も登録できます。

「プロフィール」で表示名を決めてください。レビューを頼む相手を選ぶ画面などで、ほかの所属者に見える名前です。

パスワードを忘れたら、ログインの画面の「パスワードを忘れた場合」から再設定します。メールが届かないサーバーでは、サーバー管理者に頼んでください。シングルサインオンだけでログインしている人は、IdP（会社のアカウントなど）で回復します。心当たりのないログインがないかは「セッションと履歴」で確かめられます。

## 何から始めるか

ワークスペースを開くと「やること」が出ます。あなたが対応できることが、急ぐものから順に並んでいます（レビュー待ち、差し戻し、説明を書いていない訂正、確認期限切れ、原文の更新、予約の失敗など）。開くと、対応する記事のタブが開きます。

## 記事を書く

1. 「記事」→「新しい記事」で、コンテンツタイプとロケールを選んで「作成する」を押します。
2. 内容を入力します。入力は自動で保存され、画面に「保存済み」と出ます。
3. スラッグ（英小文字、数字、ハイフン）を入れると、公開 URL が決まります。

本文のツールバーで、見出し、箇条書き、引用、コードブロック、リンク、画像、埋め込みなどを使えます。

- **画像には「代替テキスト」を入れるか、「装飾画像」の印を付けてください。** どちらもない画像があると公開できません。
- 埋め込みは、許可された提供元の https の URL だけです。
- 使える画像は JPEG、PNG、WebP、GIF です。アップロードのときに写真の位置情報などは取り除かれます。
- **メディアは URL を知っていれば誰でも見られます。** 下書きの記事で使っている画像も同じです（URL は推測できない名前になっています）。公開前の秘密の画像は置かないでください。

### 同時に編集したとき

ほかの人が編集中の記事は「{名前} さんが編集中です」と出て、閲覧だけになります。「編集を引き継ぐ」で引き継げます（権限の設定によります）。

「他の人がこの下書きを先に保存しました」と出たら、自動保存は止まっています。**読み直すと、まだ保存していない変更は消えます。** 必要な部分をコピーしてから読み直してください。

## プレビューする

記事の「プレビュー」タブで、実際のサイトでの表示を確かめられます。保存のたびに更新されます。出ないときは「別タブで開く」を使ってください。「この記事の公開URLのサイトは、プレビューを許すサイトに設定されていません」と出たら、ワークスペースの管理者に設定を頼みます。

## レビューを頼む（執筆者）

執筆者は公開できません。「レビュー」タブの「レビューを依頼する」で、公開できる人に頼みます。差し戻されたら、コメントを見て直し、また依頼します。

編集者と管理者は、依頼を見て公開するか「差し戻す」を押します。依頼がなくても公開できます。

## 公開する

1. 「公開」を押すと「公開の確認」が開きます。
2. 公開できない理由、公開 URL、変更されたセクションを確かめます。URL が変わるときは知らせが出ます（古い URL は履歴に残り、リダイレクトされます）。
3. 「ほかの記事との食い違い（AI）」が出ていれば、目を通します。AI 支援を有効にしたワークスペースだけに出ます。公開はこの結果を待たずにできます。
4. 「公開する」を押します。

公開中の記事を直して公開すると、新しい版になります。「版」タブで過去の版を見られます。

### 予約公開

「そのほかの操作」→「予約公開…」で時刻を決めます。**その時点の下書きが予約版として固定されます。** 後で下書きを編集しても予約版は変わりません。その編集も公開するには「予約し直す」を押してください。

### 非公開と削除

「非公開にする」は公開サイトから取り下げます。下書きと版の履歴は残ります。「削除する」は公開も止め、画面からは元に戻せません（管理者と編集者だけ）。どちらも、配信、検索、回答からすぐに外れます。

## 誤りを訂正する

公開中の記事の誤りを直すときは、ふつうの公開ではなく**「そのほかの操作」→「訂正として公開」**を使います。

- 訂正があったことと、影響したセクションが、読者に公開されます。**変更前の本文や差分は公開されません。**
- 「訂正の説明」に、何をどう直したかを書きます（任意）。定型文からも選べます。後から「版」タブで書き直せます。
- 旧版は、すぐに検索とチャットボットの根拠から外れます。
- 訂正は予約できません。予約がある記事を訂正として公開すると、予約は取り消されます。

数値、日付、リンクが変わっていると、公開の確認で「誤りの訂正ですか？」と知らせます。

### 版の本文を消す（管理者）

個人情報の削除依頼などで、古い版の本文を消すときは「版」タブの「本文を抹消」を使います（管理者だけ）。版の番号や日時の記録は残り、本文だけがすべての API から消えます。

- 元に戻せません。
- 公開中の版は抹消できません。問題の箇所を直した版を訂正として公開するか、非公開にしてから抹消します。
- **抹消より前に取ったバックアップには残ります。**
- 翻訳された記事に同じ内容が残っていないかも確かめてください。

## 内容を見直す（鮮度）

「鮮度」タブに「最終確認日」と「確認期限」があります。内容が今も正しいことを確かめたら「確認済みとして記録」を押します。版は作られません。メモは管理画面だけに残ります。

期限が切れた記事は「やること」に出ます。チャットボットの回答でも、断定を避けるようになります。

AI 支援が有効なら、「古くなっていそうな箇所を探す」で、バージョン番号、価格、日付、外部リンクを挙げてもらえます。

## 翻訳する

「翻訳」タブの「翻訳を作る」で、下書きを複製して別のロケールの記事を作ります。原文が更新や訂正されると「やること」に出ます。

## 公開設定

「公開設定」タブのスイッチです（変えるには「方針に関わるスイッチ」の権限が要ります）。

| スイッチ | 内容 |
|---|---|
| チャットボットに使う | この記事を回答の根拠に使います |
| 外部AI向けの素材に含める | Markdown 版や `llms.txt` に含めます |
| 学習への利用を拒否する | AI の学習に使わないよう意思表示します。クローラーへの意思表示で、技術的に止めるものではありません |

## 関連記事

「関連記事」タブで、自動で選ばれた関連記事を確かめ、固定や除外ができます（編集者と管理者）。

## AI 支援について

AI の結果には見落としや誤りがありえます。事実は自分で確かめてください。**AI 支援を有効にしたワークスペースでは、公開前の下書きが LLM の提供会社に送られます。** 予算が尽きると「今月の上限に達しました」と出ますが、公開はこれまでどおりできます。

## 困ったとき

| 表示 | すること |
|---|---|
| スキーマの移行待ちのため、編集と公開を止めています | サーバー管理者に知らせて、終わるのを待ちます。公開中の記事は配信され続けます |
| テンプレートの〜に問題があり | テンプレートの開発者に知らせます。編集者が直すものではありません |
| テンプレートの公開前のフックが、公開を止めました | 表示された理由に従って直します |
| 見つかりません | ワークスペースに所属していないか、記事が削除されています |

エラーの一覧は [エラーコード](../reference/error-codes.md) にあります。
