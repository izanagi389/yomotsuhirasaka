# ロールと権限の一覧

## インスタンスの立場

| 立場 | できること |
|---|---|
| サーバー管理者 | ワークスペースの作成と削除、テンプレートのデプロイと切り替え、全利用者の一覧、インスタンスの監査ログと通知、埋め込みのモデルの切り替えの開始、天井の決定。所属していないワークスペースも操作でき、その操作はそのワークスペースの監査ログに残ります。質問ログの閲覧は、所属して権限を付与されない限りできません |

## ワークスペースのロール

利用者は複数のワークスペースに所属でき、ワークスペースごとにロールを持ちます。

| 操作 | 管理者 | 編集者 | 執筆者 | 閲覧者 |
|---|---|---|---|---|
| 記事と下書きを見る | ○ | ○ | ○ | ○ |
| 記事の作成と編集（他の人の記事を含む） | ○ | ○ | ○ | |
| レビューを依頼する | ○ | ○ | ○ | |
| 公開、予約公開、非公開、レビューの差し戻し | ○ | ○ | | |
| 記事の削除 | ○ | ○ | | |
| 訂正として公開、確認済みの記録（権限 `corrections`） | ○ | ○ | 付与で可 | 付与で可 |
| 編集の引き継ぎ（権限 `takeOverEditing`） | ○ | ○ | 付与で可 | 付与で可 |
| 方針に関わるスイッチ（権限 `policySwitches`） | ○ | 付与で可 | 付与で可 | 付与で可 |
| LLMの接続設定と予算、回答の設定、AI支援の設定（権限 `manageLlm`） | ○ | 付与で可 | 付与で可 | 付与で可 |
| 質問ログの閲覧（権限 `viewQuestionLog`） | 付与で可 | 付与で可 | 付与で可 | 付与で可 |
| 所属者の一覧を見る（`canViewMembers`） | ○ | 付与で可 | 付与で可 | 付与で可 |
| 所属者、招待、配信APIのキー、Webhook、監査ログ、ワークスペースの設定、訂正の定型文、質問ログの設定 | ○ | | | |
| 版の本文の抹消 | ○ | | | |
| テンプレートの切り替え（権限 `switchTemplate`） | 付与で可（サーバー管理者だけが付与） | | | |

- 管理者とサーバー管理者は、多要素認証を設定しないと管理の操作ができません。
- 権限はリクエストのたびに今の状態と照合します。ロールを変えたり所属から外したりすると、すぐに効きます。

## 重い権限

管理者が、管理の「所属者」から個人に付与します（`switchTemplate` だけはサーバー管理者が付与します）。付与と取り消しは監査ログに残ります。画面の名前は次のとおりです。

| 権限 | 画面の名前 | ロールの既定 |
|---|---|---|
| `viewQuestionLog` | 質問ログの閲覧 | **どのロールにも付きません**。管理者も、自分に付与してから見ます |
| `manageLlm` | LLMの接続設定と予算 | 管理者 |
| `policySwitches` | 方針に関わるスイッチ | 管理者 |
| `corrections` | 訂正としての公開と確認済みの記録 | 管理者、編集者 |
| `takeOverEditing` | 編集の引き継ぎ | 管理者、編集者 |
| `switchTemplate` | テンプレートの切り替え | **どのロールにも付きません**。管理者にだけ、**サーバー管理者が**付与します。管理者は自分にもほかの人にも付与できません |

## 配信APIのキーの権限

| 権限（画面） | 範囲 | 使い道 |
|---|---|---|
| 読む | `read` | 記事の読み取り |
| クエリの登録 | `register` | ビルドやデプロイのときのクエリの登録 |
| 回答API | `answer` | 回答の生成。呼ぶたびに LLM の料金がかかります |

用途（ビルド用、サーバー用）は回数制限の既定値だけを変えます。権限は変えません。

## 個人トークンの権限

| 権限（画面） | 範囲 | 使い道 |
|---|---|---|
| 読む | `read` | 読み取り |
| 書く | `write` | 取り込み（`yomi import`）など |
| デプロイ | `deploy` | テンプレートのデプロイ。サーバー管理者だけが発行できます |

トークンで使えるのは、トークンの権限と、その時点の本人のロールの両方で許される操作だけです。

## 再認証が要る操作

APIキーの発行、LLMの接続設定や予算の変更、権限の変更、質問ログの閲覧、デプロイの範囲のトークンの発行など。多要素認証を設定した人は、多要素認証で確認します（パスワードだけでは通りません）。
