## 全体の考え方

- 管理画面、管理 API、配信 API、メディアは、すべてインターネットに公開する前提です。IP アドレスの制限や VPN は CMS の機能にはありません。守りはアプリの側の対策（回数の制限、多要素認証、登録済みのクエリだけの受付など）が担います。
- **回線そのものをあふれさせる攻撃（L3/L4 の DDoS）はアプリでは防げません。** CDN やクラウドの防御に任せてください。
- 動かすのは Rust のサーバーと PostgreSQL だけです。本番に Node.js は要りません。
- v1.0 は1つのインスタンスを1つのプロセスで動かす前提です。
- ワークスペースの管理者どうしは互いに信頼しない前提で作っています。サーバー管理者は信頼された運用者です。サーバー管理者がワークスペースのデータを操作すると、そのワークスペースの監査ログに残ります。

権限やエラーの意味は [共通の資料](../reference/README.md) を見てください。
