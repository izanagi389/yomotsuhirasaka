# 手順書

yomotsuhirasaka の手順書です。読む人ごとに分かれています。v1.0 では日本語だけです。

| 冊子 | 読む人 | 内容 |
|---|---|---|
| [サーバー管理者向け](operator/README.md) | サーバーを動かす人 | 導入、設定、更新、バックアップと復旧、事故対応、監視、ワークスペースの作成と天井、LLM |
| [開発者向け](developer/README.md) | サイトとテンプレートを作る人 | テンプレートとCLI、組み込みJS、配信API、Nuxtモジュール、Webhook、回答API |
| [編集者・ワークスペースの管理者向け](editor/README.md) | 記事を書く人、ワークスペースを預かる人 | 主な作業（書く・公開する・訂正する・見直す）、所属者とキーの管理 |
| [共通の資料](reference/README.md) | 全員 | 用語集、ロールと権限の一覧、エラーコードの一覧 |

同じことは2か所に書きません。共通のものは [共通の資料](reference/README.md) にあり、各冊子からリンクしています。

画面の画像は載せていません。画面やボタンの名前は、管理画面の日本語の表示のとおりに書いています。
