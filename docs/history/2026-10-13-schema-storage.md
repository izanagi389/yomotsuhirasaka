# 判断記録: 記事のデータの持ち方と、約束のテストの名前の修正

- 日付: 2026-10-13
- 状態: Q201〜Q202 決定済み
- 範囲: M1の実装（テンプレートのデプロイ）の中で持ち主に確認した点

## 決定事項

| # | 論点 | 決定 | 主な理由 |
|---|---|---|---|
| Q201 | 記事のデータのDBでの持ち方 | ワークスペースのスキーマに、コンテンツタイプごとのテーブル（`ct_<名前>`）を作り、フィールドを1列ずつ（`f_<名前>`）持たせて**下書き**を置く。デプロイの移行はこのテーブルへのDDLで行う。**公開した版**は、公開した時点のフィールドのJSONのスナップショットとして、書き換えずに残す（本文の抹消を除く）。配信は公開した版から読む。必須のフィールドは、公開のときと移行のときにコードで確かめる | 決定（Q92、Q53）の「マニフェストの名前から内部用のテーブル名・列名を作る」「移行はDDL」に沿う。版をJSONで持つと、版ごと・スキーマのバージョンごとにテーブルや列を増やさずに済み、移行待ちのワークスペースが古いスキーマで配信を続けること（Q130）や、版の本文の抹消（Q134）が単純になる |
| Q202 | 約束のテストのフィールド名 | `schema.test.ts` の `addedField` と `extraFieldV2` を、`added_field` と `extra_field_v2` に直す。約束の文と期待値は変えない | INV-SCH-06（英小文字・数字・アンダースコア以外の名前は拒否）と食い違っていたため |
